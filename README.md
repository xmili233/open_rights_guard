# Open Rights Guard

> 希望成为 AI 时代下数字版权的坚强守护者。

Open Rights Guard 是一个面向数字内容版权保护的开源 AI Agent 项目，目标是把侵权线索发现、内容识别、证据整理和处置协作连接成一条可审计的工作流。

## 为什么做这个项目

数字内容传播越来越快，侵权形式也从简单转载发展到改图、变体文字、切片视频和跨平台搬运。传统人工巡检覆盖有限、取证分散，权利人很难持续追踪和处理。

本项目希望让 AI 负责高频、重复的信息处理，让人负责权利确认、风险判断和最终处置。

## 计划能力

- 监测公开网页中的疑似侵权内容
- 使用文本与多模态模型识别内容及其变体
- 保存时间、来源、截图与内容哈希，形成可追溯证据包
- 按可信度和影响范围生成待人工复核的风险队列
- 辅助生成平台投诉材料、律师复核材料和处置记录
- 记录每次判断、人工确认和后续结果，持续改进识别策略

## MVP

第一版只打通一条最小闭环：

1. 输入原创内容和待检查 URL
2. 抓取公开可访问的页面内容
3. 计算文本或图片相似度
4. 生成人工复核报告和证据摘要
5. 导出结构化 JSON 与可阅读的 Markdown 报告

## 设计原则

- **人类最终决策：** AI 只提供线索和草稿，不自动认定侵权或发起法律行动。
- **证据可追溯：** 保存来源、时间、原始材料、哈希和处理记录。
- **合规优先：** 只处理合法获得且获授权使用的数据，不绕过登录、访问控制或平台安全机制。
- **模型可替换：** 业务流程不绑定单一模型或供应商。
- **结果可验证：** 用召回率、误报率、人工复核成本和处置结果衡量价值。
